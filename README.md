# 阶跃娘投稿流程 · 隔离验收仓库

**这里只做合成测试，不接收正式投稿，不是素材站，也不是正式审核入口。**

正式仓库为 7oMB2006/stepniang-materials，本仓库不修改其 main、开关、索引或保护规则。

## 测试范围

- 真实外部 Fork PR 的新作品投稿、再次投稿、作者资料修改及撤下申请校验。
- config/intake.json 的 open: true 仅为此独立仓库的测试配置，不代表正式开放。
- known 是合成作者 ID；与公开小号数字 ID 的映射只测试门禁，不建立正式作者绑定。
- 所有图片均为生成的几像素纯色图；没有真实作品、邮箱、社交主页、令牌或本机数据。
- 数字账号检查使用真实 PR 事件，依然要求人工审核；绿灯不表示收录或发布。
- 测试 PR 验收后关闭、不合并，保留测试历史。撤下 PR 不执行删除。

## 代码来源与差异

源码来自 7oMB2006/stepniang-materials@a1ab26501cb134e93ff2c5ab324013a7f0130cfd 的 29 个已公开文件，没有上传站点源码。
